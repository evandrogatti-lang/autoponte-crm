# Repository execution rules

Read and follow `docs/agents/AGENT_JOB.md`,
`docs/agents/AUTOPONTE_SLICE.md`, and
`docs/agents/AUTOPONTE_VALIDATION.md` before executing a task.
Read the relevant Task Contract and checkpoints.
Preserve their IDs, scope, authorization, validation, and stop conditions.
Skill instructions do not expand an approved Task Contract.

## Agent skills

### Issue tracker

Tasks and issues are local files in `docs/agents/`, following the
existing Task Contract and checkpoint conventions.
See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`, when present.
See `docs/agents/domain.md`.
